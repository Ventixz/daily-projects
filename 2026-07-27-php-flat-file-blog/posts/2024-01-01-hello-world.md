This is the first post on a blog with **no database**. Every entry here is a
Markdown file sitting in the `posts/` directory, and the front controller reads
them straight off disk on every request.

There's no admin panel. Publishing a post means:

- writing a `.md` file with a front-matter header
- dropping it in `posts/`
- refreshing the page

That's the whole workflow.
