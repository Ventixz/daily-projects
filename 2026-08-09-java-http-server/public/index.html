It's a raw socket, all the way down.

This page, its stylesheet, and the two /api routes below are all served by HttpServer -- no servlet container, no com.sun.net.httpserver, just a ServerSocket and hand-rolled HTTP/1.1 parsing.

  • /api/time -- current server time as JSON
  • /api/echo?msg=hello -- echoes a query param as JSON
  • /about.html -- a second static page, different content type story
  • /missing.html -- 404 demo
